# Mã nguồn các mô-đun công trình (v156)

- `c15.js`: nhà drone tấn công, súng phun lửa, tia laser/nỏ thần...
- `c16.js`: công trình bảo trì (drone sửa chữa, kho vật tư, ga-ra cứu hộ, trạm y tế) và khung mô phỏng xem trước.
- `c17.js`: 25 công trình mới của v154–v155 (bể na nô giáp trắng, trạm tái chế phế liệu, mô-đun hồi sinh, xưởng cơ khí trung tâm, triệu hồi tàu chiến, phát hiện tàng hình, tháp tín hiệu xanh, bản đồ chiến thuật, phòng thí nghiệm lõi năng lượng, đài thiên văn, trung tâm dữ liệu, tháp chỉ huy trung tâm, viện nghiên cứu cầu quang, vòm kính, bộ chỉ huy tối cao, dàn pin mặt trời, dãy ắc quy trụ, lò phản ứng plasma, tổ máy phát hơi nước, tụ điện cao thế, trạm truyền năng lượng, bộ pin dự trữ, lò hợp hạch mini, cuộn tích điện Tesla, lò hợp hạch trung tâm) kèm giao diện đặt làn khói và mô phỏng xem trước.
- `c18.js`: 24 công trình khai thác & phòng thủ của v156 (máy đào quặng mini, giàn khoan tinh thể, xưởng chưng cất nhiên liệu, máy tuyển quặng, trạm phân loại khoáng sản, lò nung hơi nước, lò đúc robot, lò tinh luyện đạn quỷ, kho tạo tàu, các tháp súng/pháo/tên lửa, tháp khiên năng lượng, radar đánh chặn, pháo đài đa năng, pháo plasma, pháo gauss, pháo ba nòng xiên, pháo mảnh văng) — hệ đạn riêng, cộng sản lượng vào phần thưởng Level/PvP, mô phỏng xem trước.
- `ed35.py`, `ed36.py`, `ed37.py`, `ed38.py`: script chèn các mô-đun trên vào file game một-file (`index.html`).
- `warship.b64`: ảnh tàu chiến 2D dùng cho công trình Triệu hồi tàu chiến.

File chạy game là `index.html` (kèm `imgs1.js`…`imgs10.js`).
